# 合规红线库 · Reference

> **来源**：HR 在飞书表「面试官复盘语料」的「红线」sheet 整理的正反案例（2026-08）＋ 确认表「HR 可增补」栏。
> **用途**：复盘系统的**最高优先级判定清单**。任何一条命中 → 该维度记 0 分、综合评级直接压至 C 以下（D 档只看本清单）；命中多条 → D 档（不合格 / 关账号标准）。这是 HR 最刚需的信号，报告必须在最醒目的位置单独标出，不并入普通「高/中」严重度。
> **判定原则（会议 2026-08-06 确认）**：每条红线都要能区分「正常提问 / 观点输出 / 恶意表述」三类边界，用正反案例校准，不以字面命中为准——**问婚育是红线，陈述岗位客观约束不是；质疑数据是施压，说"你作弊"是攻击**。

## 红线全表（9 类）

| # | 红线 | 判定要点 | 正面 / 反面案例 |
|---|---|---|---|
| 1 | **禁止询问薪资** | 面试官不主动问薪资；候选人问时引导回面试内容，不接话 | 见下 §1 |
| 2 | **严禁不文明用语**（贬损 / 质疑 / 脏话 / 人格侮辱） | 对候选人评价对事不对人；质疑用中性问法 | 见下 §2 |
| 3 | **严禁消极用语**（抱怨公司 / 否定候选人 / 流露负面情绪） | 负面信息换成岗位客观要求去问 | 见下 §3 |
| 4 | **严禁当场反馈结果**（通过、不通过、或"我觉得你行/不行"） | 结尾缓冲 + 说明 HR 会联系，不表态不预告 | 见下 §4 |
| 5 | **严禁时长不足**（正职 ≥20min / 实习 ≥15min） | 开场约定时长；主动控场用足时间 | 见下 §5 |
| 6 | **严禁歧视性提问**（婚育/年龄/地域/性别/户籍等与岗位无关的敏感问题） | 只问岗位客观要求，不问私人身份与计划；敏感话题零预判 | 见下 §6 |
| 7 | **严禁人身攻击**（压力面中超出对事范围、贬低候选人人格） | 压力施压只对方案/数据，可要求验证，不可归罪人格 | 见下 §7 |
| 8 | **严禁涉隐私恶意提问**（刺探隐私、带羞辱性） | 敏感背景中性询问，不带预判 | 见下 §8 |
| 9 | **禁止面试关闭摄像头** | 线上会议全程保持视频开启 | — 转录无痕，靠会议元数据（视频开关状态）检测；无元数据时转为自评提醒 |

## 各红线正反案例

### §1 禁止询问薪资
- ⛔ 反：「你上家公司给你开多少？」「你期望薪资是多少？我们好评估一下。」「我们这个岗位预算有限，你最低能接受多少？」「我看你期望写的 4 万，我们给不到，你考虑降薪吗？」
- ✅ 正（候选人问薪时）：「薪资方案由 HR 团队统一负责，后续与 HR 详细沟通。今天我们还是先深入聊聊您的项目经验。」
- 边界：**人选主动问** → 面试官引导回面试内容即可，不算红线；面试官主动问薪资 / 压价 → 红线。

### §2 严禁不文明用语（贬损 / 质疑 / 脏话 / 人格侮辱）
- ⛔ 反：「你这简历写得也太垃圾了吧？逻辑完全不通。」「你连这个基础工具都不会用？你哪个学校的？」「我觉得你这个技术很落后，你们当时咋想的？」「你这回答完全跑偏了，我问的根本不是这个问题。」
- ✅ 正：「我看您在简历中描述的这段经历，时间线逻辑与常规有点差异，方便您帮我梳理一下吗？」「我们这个岗位对 XX 工具的操作有硬性要求。请问您是否有过相关实操经验？或者有其他替代工具的使用经验吗？」「你现在回顾当时的方案，你还会继续选择这个方案吗？为什么？」「您的这个角度挺有意思的。不过我想追问一下，如果从 XX 方向来思考，您会怎么处理？」
- 边界：**对事质疑**（时间线差异、能力匹配）≠ **对人贬损**（垃圾、哪个学校、落后、跑偏）。质疑方案永远可接受，贬损人格不可接受。

### §3 严禁消极用语（抱怨公司 / 否定候选人 / 流露负面情绪）
- ⛔ 反：「我们部门天天加班到凌晨，内卷很严重，你抗压能力强吗？」「既然你来了，丑话说在前头，我们这流动率挺高的。」「我们绩效强制排名的，你能接受吗？」「绩效淘汰很正常啊，干不好就走。」
- ✅ 正：「我们这个团队目前处于快速冲刺期，节奏比较紧凑。请描述一次您在高压下完成复杂项目的经历。」「我们希望找到能与团队长期共同成长的伙伴。您对于一份工作的理想年限是怎样的？」「想了解一下，您过往经历中遇到过的最严格的绩效挑战是什么？您是如何应对的？」
- 边界：**把岗位的真实客观要求讲清楚**（节奏紧凑、有时需加班）≠ **传播负面情绪**（内卷严重、流动率高、干不好就走）。

### §4 严禁当场反馈结果（通过、不通过、或"我觉得你行/不行"）
- ⛔ 反：「我觉得你今天表现不错，肯定能进二面，你等我通知」「我觉得你挺合适的，等我推荐给业务老大就行。」「你回家等通知吧。」（只有这一句话，无任何过渡）「应该不太行吧」「我觉得挺好，等复试吧」
- ✅ 正：「面试的正式环节已结束。接下来大概有 3-5 分钟时间，您有什么想问我这边的问题吗？」（先缓冲，再结束）「后续 HR 会及时联系您反馈面试结果和下一步安排，一般是 5 个工作日内。」
- 边界：**告知流程**（HR 会联系、时限）≠ **表态结果**（行 / 不行 / 看好）。过渡句是缓冲，不是预告。

### §5 严禁时长不足（正职 ≥20min / 实习 ≥15min）
- ⛔ 反：（10 分钟结束）「我没什么问题了，你还有什么想问的吗？没有就结束吧」「我看你简历挺合适的，不用聊太久，5 分钟就行。」（13 分钟结束实习生面试）「时间差不多了，就到这吧」（8 分钟结束）「行，那你先回去吧。」
- ✅ 正：（开场定基调）「今天的面试大约安排 30 分钟（正职）/ 20 分钟（实习），前 20 分钟我来提问，后 10 分钟留给您提问。」（15 分钟左右主动控场）「我们刚聊完了您的项目 A 和项目 B，接下来我想再花 5 分钟深入了解一下您在项目 C 中的具体角色。」（16 分钟时）「最后我再追问一个开放性问题，想看看您的应变潜力。」（22 分钟时）「好的，技术层面的交流就到这里。接下来我给您介绍一下我们团队目前的人员构成和分工情况。」
- 边界：**面试总时长**红线为下限（正职 20 / 实习 15）；**参考时长**为正式 40–60min、实习 20–30min（见 toolkit，属量化快照目标而非红线）。

### §6 严禁歧视性提问（婚育/年龄/地域/性别/户籍等）
- ⛔ 反【婚育】：「你结婚了吗？有孩子吗？打算什么时候要二胎？」「小孩这么小，你怎么平衡工作和家庭？能接受加班吗？」「你刚结婚，近期有生育计划吧？我们这很忙的。」
- ⛔ 反【婚育观点】：「女生做技术，还是不如男生能扛得住压力吧？」（**这是"观点输出"，比直接提问更隐蔽，同样踩红线**）
- ⛔ 反【年龄】：「你都 35 了还在面试这个级别？会不会太晚了？」「你年纪太小了，能管得住团队里的人吗？」
- ⛔ 反【地域】：「你是 XX 省的？那边的人做事风格跟我们这不太搭吧？」「你老家在东北，能适应我们南方的气候和饮食吗？」
- ⛔ 反【性别】：「这岗位经常要搬设备，男生比较合适，你是女生能行吗？」「女孩子家家的，这行经常熬夜，你爸妈同意吗？」
- ⛔ 反【户籍】：「你是外地户口，我们这需要本地人担保，能搞定吗？」
- ⛔ 反【其他敏感】：「你信佛啊？会不会因为吃素影响团队聚餐？」
- ✅ 正（陈述岗位客观约束，不涉私人计划）：「这个岗位需要频繁出差，有时需连续一周驻场，想了解一下您在时间安排上是否有特殊的限制？」「我们团队工作强度较大，项目紧急时需协同加班。请举例说明您在过往工作中是如何处理高强度任务与个人事务冲突的。」（直接陈述岗位的实际时间要求，让候选人自行评估，不做任何对"生育计划"的询问或预判）
- ✅ 正（聚焦能力，不关联身份）：「我们这个岗位对技术深度和抗压能力要求较高。请描述一次您独立攻克技术难题的经历。」「这个岗位需要 X 年以上的行业经验。请您重点介绍一下您最近 3 年负责的核心项目和成果。」「这个岗位需要带领 5 人左右的团队。请分享一次您推动团队达成共识或解决冲突的经历。」
- ✅ 正（跳过地域 / 只问客观情况）：「请介绍一下您上一份工作的团队协作模式和汇报关系。」「我们这个岗位 base 在上海，请问您目前的居住地以及通勤时间大概是怎样的？」
- ✅ 正（客观体力要求，不带性别预设）：「这个岗位涉及设备搬运和现场调试的体力环节。我们想确认一下您的身体状况是否能够胜任这类工作场景？」「这个岗位项目期有夜班轮值安排。请您描述一下您过往对夜班或轮班工作制的适应情况。」
- ✅ 正（聚焦流程要求，不问户籍）：「我们的岗位入职流程中需要提供【XXX 证明材料】，请问您这边是否具备相应的办理条件？」
- ✅ 正（其他敏感 → 换成团队活动意愿）：「我们团队团建频率大概是一月一次，您对团队融合活动的参与意愿是怎样的？」
- ⭐ 边界三分法：**① 正常提问** = 只问岗位客观要求（出差 / 体力 / base / 材料），不关联身份；**② 观点输出** = 对某类人贴标签（"女生做技术还是不行"），比直接提问更需警惕；**③ 恶意表述** = 直接问私人计划或做贬损预判。①②③ 中只有 ① 合法，②③ 都是红线。

### §7 严禁人身攻击（压力面中超出对事范围、贬低候选人人格）
- ⛔ 反：「你这个项目数据这么好，是不是作弊/造假了？」「你才工作两年，怎么可能独立负责这么大的项目？吹牛吧你。」「你这个方案太蠢了，正常人都不会这么想。」
- ✅ 正（用客观验证代替主观质疑）：「您刚才提到的这个项目数据非常亮眼。为了确保理解一致，方便共享屏幕或提供脱敏材料，具体展示一下当时的执行链路吗？」「这个项目的规模和复杂度都不低，想详细了解一下您在其中的具体分工和决策权限是怎样的？」「这个方案的逻辑我之前接触得不多，想追问一下您当时的决策依据是什么？有没有评估过其他方案？」
- 边界：**怀疑数据真实 → 请求验证**（共享屏幕 / 脱敏材料，会议明确给过这个替代话术）≠ **怀疑人的人品**（作弊、吹牛）。压力面可追问可施压，不可归罪人格。

### §8 严禁涉隐私恶意提问（刺探隐私、带羞辱性）
- ⛔ 反：「你之前的领导是不是对你有意见，才把你裁掉的？」「你简历空窗期这么久，一直在家里蹲着吗？」
- ✅ 正（中性询问，不带预判）：「方便了解一下您上一份工作的离职原因和当时的考虑吗？」「我注意到您的简历中有 X 个月的空窗期，方便介绍一下这段时间您在做什么规划吗？」
- 边界：**问客观经历**（离职原因、空窗期在做什么）≠ **带羞辱预判**（领导对你有意见、家里蹲）。

## 检测与报告规则

- 命中任意红线 → 对应维度记 **0 分**（不受其他表现影响）。
- 命中 1 条 → 综合评级**压至 C 以下**；命中多条 / 触及 §6-§8 人身攻击、歧视、恶意隐私 → **D 档（不合格）**。
- 红线**单独成区**展示在报告最醒目的位置（独立于普通"待改进"表格），带时间戳原话证据。
- 判定参照：所有红线都要过一遍正反案例找齐边界，**字面命中 ≠ 红线**（如上各节"边界"说明）；拿不准时宁可标"疑似需 HR 复核"也不降红线为普通问题。
- A4 招聘压力 / A5 寻找超人（判断偏差类）归入 [[interview-toolkit.md]] §二 A，**暂保留为自评提醒**，待灰度验证后再定去留——不算红线。
